## 8. 已发现的问题与负结果（全部列出）
1. 历史电路：开关可置零、nullifier 秘密可自选、46,593 不含问责、多个论文数字无出处（E0 / E1）。
2. 证书撤销条目没有 salt：知道两端公钥并有 (cap, expiry) 窄先验时，可以识别撤销（E3 L3，单线程 JS 演示 35 s）。
3. 运营方重新发布旧根，可以"撤销撤销"（E3，#18）。根发布权限与单调性未定。
4. 每次根更新都使全部见证失效；可用性依赖 Δ（E3.3 / E3.5）。
5. 方案 A 的错误打开在输出上无法察觉（E6）；方案 C 可以自查。
6. 门限打开依赖可信 dealer；≥ t 个委员会成员可以打开任意动作（治理问题，不是密码学问题）。
7. 追责随机数由证明者选择：证明者可以让自己的动作可关联（只损害自己）。
8. v7 D = 3 起超过 2^17，证明时间跳变（1.46 s → 约 2.1 s）。
9. 能力模型只有 32 位子集 + 过期（#16），论文的"预算"类用例目前没有实现。
10. 主代理（ent[1]）不进撤销集，由重新注册替换处理（设计决定）；在根窗口内旧证明仍有效（v6 A18d / A17c，POLICY）。
